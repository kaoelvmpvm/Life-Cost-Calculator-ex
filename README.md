# 經彩人生・月經平權挑戰

由 [Life-Cost-Calculator](https://github.com/kaoelvmpvm/Life-Cost-Calculator) 的原有生涯成本試算教材改編為情境式闖關體驗，使用**同一套計算公式與價格假設**。

## 操作

入口：`index.html`。若已開啟 GitHub Pages，預期網址為：

https://kaoelvmpvm.github.io/Life-Cost-Calculator-ex/

學習流程：

1. **第一～二關｜角色成本解密**：五位虛構角色隨機分派一位。依據角色設定調整七項參數與四項勾選開銷，再輸入生涯總金額作為通關密碼。**參數與金額皆需正確**，不能單靠猜出密碼過關。
2. **第三關｜當開銷成為負擔**：將角色金額轉換為奶茶、便當、iPhone 與日本來回機票；回答原教材的月經貧窮與課稅問題。純記錄，不判斷立場正誤。
3. **第四關｜校園平權決策**：回答生理用品可近性與隱私、生理假與實質平等兩個原教材問題。純記錄，不判斷立場正誤。
4. **第五關｜經彩平權倡議者**：使用原有 Google Apps Script 投票服務，完成 Q1、Q2。新版 Apps Script 可回報兩題皆完成；未更新時可使用**明確標示的學生自行確認**備援。
5. **學習證書**：彙整角色、成本、四項換算、三項回答與兩題投票完成狀態。使用瀏覽器「列印／另存 PDF」產生 A4 學習單。

課堂投票原題目、選項與資料表仍由既有 Google Apps Script 提供，不需新建試算表。

## 重要功能與限制

- 所有故事角色為**虛構的教學試算設定**，不代表任何特定學生的月經經驗或費用。
- 不需要登入、沒有上傳學生思辨答案的程式。角色、文字回答與姓名欄位僅存在目前瀏覽器分頁的 `sessionStorage`，可在刷新後恢復；如需長期保存請列印成 PDF。使用共用電腦時，完成後應重新開始或關閉分頁。
- 證書記錄投票**完成與確認方式**，**不記錄投票選項**，避免展示涉及個人經驗的 Q1 答案。
- 當 Apps Script 尚未更新回傳完成訊號，證書會標示「由學生自行確認（非雲端驗證）」。不得將自行勾選視為已由資料庫查核。
- 想啟用真正的「完成兩題後自動解鎖」，請照 [Apps Script 同步設定說明](apps-script/SETUP.md) 替換原有兩份程式並重新部署。
- Google 投票使用瀏覽器匿名識別碼防重複，但更換瀏覽器或裝置仍可能重投；不等同實名一人一票。
- 遵循原教材計算假設：一年 12 次月經；無通膨、未來物價或個人醫療差異預測。

## 原公式回歸測試

```bash
node --test tests/*.test.cjs
```

五位角色的通關金額會由原公式自動計算，並由回歸測試驗證。為維持闖關體驗，本說明不直接列出密碼。

## 目錄

- `index.html` — 封面、闖關畫面、思辨問題、雲端投票和證書模板
- `css/game.css` — 響應式 UI 及 A4 列印
- `js/cost-model.js` — 原版計算公式（直接複製，未修改）
- `js/roles.js` — 五位虛構人物及參數設定
- `js/game.js` — 關卡引擎、答案驗證、暫存、證書、雲端完成通知
- `js/config.js` — 既有雲端投票公開網址
- `apps-script/Code.gs` — Google 試算表投票後端（新增完成通知模板）
- `apps-script/VoteApp.html` — 投票 UI（在收到後端回應時通知學習網站）
- `tests/game.test.cjs` — 關卡、模型與內容靜態回歸測試
