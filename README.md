# 經彩人生・月經平權挑戰

本專案由原本的 [月經平權生涯成本試算器](https://github.com/kaoelvmpvm/Life-Cost-Calculator) 改編為獨立的情境闖關教材，沿用**原有試算公式、成本假設、思辨題目與第五關兩題選項**。

## 遊戲方式

1. **第一～二關｜角色成本解密**：五位虛構角色隨機出現一位。閱讀隨機角色的生活故事，自行推理七項生理參數與四項延伸開銷。按「計算」只顯示金額，不提示是否正確；按「確認通關」才比對情境設定及金額。**參數與密碼都必須正確**。
2. **第三關｜當開銷成為負擔**：把角色生涯成本換算成奶茶、便當、iPhone、日本來回機票。閱讀月經貧窮與課稅議題，輸入自己的思辨回答，純粹紀錄、不評分。
3. **第四關｜校園平權決策**：閱讀「免費生理用品設置與隱私」、「生理假與實質平等」，分別回答兩道原有思辨題，純粹紀錄、不評分。
4. **第五關｜經彩平權倡議者**：保留原教材兩道問題與各三個選項，學生**各選擇一個個人意向**，即時收到與選項相應的鼓勵與思考方向，無須登入、不顯示其他人的答案與統計。
5. **闖關學習證書**：完成第五關後，自動顯示角色試算金額、生活換算、三段思辨原文，以及**第五關兩道選題的個人選項與個別回饋**。可列印或另存成 PDF 學習單。

## 資料儲存與隱私

- **本闖關版本完全不串接 Google Apps Script，也不連接 Google 試算表**。第五關資料不會上傳，不會產生班級投票結果。
- 姓名／座號（選填）、隨機角色、進度、思辨文字、兩道個人意向僅保存於使用者瀏覽器的 `sessionStorage`，重新整理通常仍可恢復；關閉分頁後資料是否保留依瀏覽器而定。需長期保存請另存 PDF。
- Q1 涉及個人或他人的生理用品使用經驗。學生選擇會出現在自己的證書，**對外分享證書時請注意個人隱私**。
- 角色是虛構的教學設定，學生必須從敘事情境推知設定，頁面不再提供數值對照表；計算維持每年 12 次月經等原教材假設，不等於對個人未來支出或物價的預測。
- 若從曾串接雲端的舊版遊戲更新，系統會保留能恢復的角色與思辨回答，但必須**重新完成第五關兩題意向**，才能取得新版證書。

## 測試

```bash
node --test tests/*.test.cjs
```

測試確保五個角色的金額、原試算公式、知識文字與六個選項、第五關不含雲端服務，以及 A4 列印樣式。為保留闖關樂趣，不公開五位角色的密碼。

## 主要檔案

- `index.html`：封面、五關體驗、單選題及證書。
- `css/game.css`：介面、響應式與 A4 印刷樣式。
- `js/cost-model.js`：沿用原始計算公式。
- `js/roles.js`：五位虛構角色與參數。
- `js/game.js`：計算密碼驗證、文字紀錄、個人意向保存與證書列印。
- `js/feedback.js`：第五關六種意向的對應鼓勵回饋。
- `css/refinement.css`：低飽和深藍綠／暖杏配色、過場動態、響應式圖片呈現與列印尺寸。
- `tests/game.test.cjs`：回歸測試。
